# References

This file lists the sources behind the claims in this course: dates, attributions, translations, and the readings of each thinker the chapters rely on. Use it to check a claim or to read further. Quotations from public-domain books were checked word for word against the Project Gutenberg texts bundled in [readings/](readings/README.md) (Bentham's *Introduction* and Kant's essay on lying, which are not on Gutenberg, against Internet Archive scans); the Gutenberg page for each book is listed under the chapters that quote it. Books still in copyright are listed under each chapter's **Books** heading as plain bibliographic entries.

Each online source has two links: **original** (the live page) and **archived** (a fixed copy, in case the original moves or changes). For most pages the archived copy is a snapshot in the Internet Archive's [Wayback Machine](https://web.archive.org/). The Wayback Machine does not return pages from the Stanford Encyclopedia of Philosophy, so for every SEP entry (there are 134) the archived link is instead the SEP's own dated archive edition, `https://plato.stanford.edu/archives/fall2026/entries/<slug>/`, which the encyclopedia keeps unchanged and recommends for citation. The SEP's withdrawn entry "Computer and Information Ethics" is cited from its last archive edition (Summer 2020). The 7 links with no snapshot anywhere (five DOI links to journal articles, one recent Project Gutenberg page and one Internet Archive scan, which the Wayback Machine does not archive) are marked "archived: none available"; a DOI is itself a persistent identifier.
